# Тапсырма 12. Кезеңдік шығару

## Үш стратегияны салыстыру
| | Staged rollout (1→10→50→100%) | Жабық тестілеу (closed/internal) | Бірден толық шығару |
|---|---|---|---|
| Кім алады | Production пайдаланушыларының кездейсоқ үлесі | Тек шақырылған тестерлер тізімі | Барлығы бірден |
| Тәуекел | Төмен: қате 1% пайдаланушыға ғана әсер етеді | Өте төмен, бірақ аудитория аз әрі «мейірімді» | Жоғары |
| Кері байланыс | Нақты құрылғылар мен сценарийлер, Vitals статистикасы | Сапалы, бірақ аз | Тез, бірақ кеш болуы мүмкін |
| Жылдамдық | Баяу: 3–7 күн | Тестілеу кезеңі + кейін бәрібір шығару | Ең жылдам |
| Тоқтату | **Halt** — жаңа орнатулар тоқтайды (алғандар қалады) | Тректі жаңарту | Тек жаңа нұсқамен |
| Қашан | Әр production релизі | Үлкен өзгерістер, жаңа функциялар, бета | Қауіпсіздік hotfix (қайта тестіленген) немесе өте аз аудитория |

## Менің жоспарым
| Кезең | Үлес | Ең аз ұзақтығы | Келесіге өту шарты |
|---|---|---|---|
| 0 | internal (тестерлер) | 1 күн | Чек-лист өтті, жаңа крэш жоқ |
| 1 | 1% | 24 сағ | төмендегі тоқтату шарттарының ешқайсысы орындалмады |
| 2 | 10% | 48 сағ | сол |
| 3 | 50% | 48 сағ | сол |
| 4 | 100% | — | — |

## Тоқтату (halt) критерийлері
| Метрика | Көзі | Шегі | Әрекет |
|---|---|---|---|
| Crash-free users | Crashlytics | < 99.0 % немесе алдыңғы нұсқадан 0.5 п.п. нашар | **Halt** |
| Жаңа fatal issue | Crashlytics alert | > 0.5 % пайдаланушыға әсер етеді | **Halt** |
| User-perceived ANR rate | Android Vitals | > 0.47 % (Play-дің «нашар мінез-құлық» шегі) | **Halt** |
| User-perceived crash rate | Android Vitals | > 1.09 % | **Halt** |
| Рейтинг / жаңа пікірлер | Play Console → Ratings | 3 күн ішінде орташа ≥ 0.3 жұлдызға түссе немесе 1★ пікірлер толқыны | Тексеру → Halt |
| Cold start | Vitals | > 5 c (slow cold start) өскен | Тексеру |
| Пайдаланушы шағымдары | Issue tracker / e-mail | бір қате бойынша ≥ 3 | Тексеру |

## Консольде баптау
**Production → Create new release** → AAB → **Rollout percentage: 1%** → Start rollout.
Кейін: Production → Releases → **Manage rollout → Update rollout** (10% → 50% → 100%) немесе **Halt rollout**.
CI арқылы: Actions → **Rollout control** → fraction `0.1`, status `inProgress` (тоқтату: `halted`).

> Жеке аккаунттың production-ға қолжетімділігі болмаса: процесті Play Console скриншоттарымен (закрытое тестирование треці)
> және `rollout.yml` конфигурациясымен көрсетіп, кестедегі шешімдерді сипаттаңыз.

Есепке: Manage rollout диалогы 10%-бен, Release dashboard.
