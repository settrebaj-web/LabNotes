# Тапсырма 6. Жеткізу форматы: AAB және APK

## Сборка
```bat
gradlew.bat bundleRelease     :: → app\build\outputs\bundle\release\app-release.aab
gradlew.bat assembleRelease   :: → app\build\outputs\apk\release\app-release.apk
```
Немесе Android Studio: **Build → Generate Signed App Bundle or APK…**

## Салыстыру
| | AAB (Android App Bundle) | APK |
|---|---|---|
| Не | Жариялау форматы: код + барлық ресурстар + метадеректер | Орнату форматы: құрылғыға дайын пакет |
| Тікелей орнату | Жоқ (bundletool арқылы ғана) | Иә |
| Кім қолданады | Google Play (2021 ж. бастап жаңа қосымшаларға міндетті), RuStore да қабылдайды | RuStore, AppGallery, GitHub Releases, тікелей тарату |
| Жүктелетін өлшем | Аз: Play әр құрылғыға тек қажетті ABI/тығыздық/тіл бөлігін (split APK) береді | Барлық ресурс бір файлда |
| Қол қою | Upload key; соңғысына Google қол қояды | Сіздің кілтіңіз |
| Өлшем (LabNotes 0.1.0) | 4 198 763 Б (4.0 МБ), оның ~2.4 МБ — `BUNDLE-METADATA` (R8 mapping, baseline profile), құрылғыға жүктелмейді | 1 896 766 Б (1.81 МБ) — бүкіл қосымша |

Нақты құрылғыға жүктелетін өлшемді көру:
```bash
java -jar bundletool.jar build-apks --bundle=app-release.aab --output=app.apks --connected-device --ks=... --ks-key-alias=upload
java -jar bundletool.jar get-size total --apks=app.apks
```

## Құрылғыда тексеру
- Эмулятор: APK файлын эмулятор терезесіне апарып тастаңыз (drag & drop), немесе `adb install -r app-release.apk`.
- Нақты телефон: USB debugging қосып, `adb install`; немесе файлды телефонға жіберіп, төмендегі нұсқаулық бойынша.

## Пайдаланушыға арналған орнату нұсқаулығы (APK)
1. GitHub Releases бетінен `LabNotes-x.y.z.apk` файлын телефонға жүктеп алыңыз.
2. Жүктеу аяқталғанда хабарламаны немесе **Файлдар → Жүктеулер** ішіндегі файлды басыңыз.
3. «Бұл көзден орнатуға рұқсат жоқ» деген хабар шықса:
   - **Android 8.0+**: **Баптаулар** батырмасын басыңыз → **Осы көзден рұқсат ету** (Разрешить из этого источника) қосқышын қосыңыз → артқа.
     (Жол: Баптаулар → Қосымшалар → Арнайы қолжетімділік → Белгісіз қосымшаларды орнату → Chrome/Файлдар.)
   - **Android 7 және төмен**: Баптаулар → Қауіпсіздік → **Белгісіз көздер** (Неизвестные источники). LabNotes Android 8.0-ден бастап жұмыс істейді.
4. **Орнату** → **Ашу**.
5. Google Play Protect ескертсе: «Бәрібір орнату» (қосымша Play-де тексерілмегендіктен).
6. Қауіпсіздік үшін орнатқаннан кейін «Осы көзден рұқсат ету» қосқышын қайта өшіріңіз.

Жаңарту: жаңа APK-ны дәл осылай орнатыңыз — деректер сақталады (қолтаңба бірдей болса).
Ескі нұсқадан жоғары versionCode қажет; басқа кілтпен қол қойылған APK «Қосымша орнатылмады» қатесін береді.

Есепке: эмулятордағы/телефондағы орнату экрандары, AAB/APK өлшемдері.
