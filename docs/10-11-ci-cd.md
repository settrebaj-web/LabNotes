# Тапсырма 10–11. CI/CD (GitHub Actions)

| Файл | Іске қосылуы | Не істейді |
|---|---|---|
| `.github/workflows/ci.yml` | әр push (v* тегтерінен басқа) және pull request | ktlint → detekt → Android Lint → unit-тесттер → `assembleDebug` → APK артефакт |
| `.github/workflows/release.yml` | `v*` тегі | тег = version.properties тексерісі → қол қойылған AAB+APK → mapping сақтау → **Play internal** → GitHub Release → ⏸ **қолмен растау** → production 1% |
| `.github/workflows/rollout.yml` | қолмен (Actions → Run workflow) | production үлесін 10/50/100% көтеру немесе `halted` |

## Бір реттік баптау
1. GitHub-та репозиторий жасап, жобаны жіберіңіз (Android Studio: **Git → GitHub → Share Project on GitHub**).
2. **Settings → Secrets and variables → Actions → New repository secret**:

| Secret | Мәні |
|---|---|
| `KEYSTORE_BASE64` | upload keystore base64 (05-signing.md, 4-қадам) |
| `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` | keystore.properties-тегі мәндер |
| `PLAY_SERVICE_ACCOUNT_JSON` | төмендегі сервис-аккаунт JSON файлының толық мәтіні |
| `GOOGLE_SERVICES_JSON` | `app/google-services.json` мазмұны (міндетті емес) |

3. **Play API кілті**: Google Cloud Console → жаңа жоба → *Google Play Android Developer API* қосу →
   IAM → Service accounts → Create → Keys → Add key → JSON. Play Console → **Users and permissions → Invite new user** →
   сервис-аккаунт e-mail-ы → LabNotes қосымшасына *Release to testing tracks* + *Release to production* құқықтары.
4. **Қолмен растау**: Settings → Environments → New environment `production` → **Required reviewers** → өзіңізді қосыңыз.
5. (Жеке аккаунт) Settings → Variables → `PROMOTE_TRACK` = `alpha` (closed testing), әйтпесе production.

## Жергілікті тексеру (CI-мен бірдей)
```bat
gradlew.bat ktlintFormat          :: стильді автоматты түзету (бірінші рет міндетті түрде іске қосыңыз)
gradlew.bat ktlintCheck detekt lintDebug testDebugUnitTest assembleDebug
```
Есептер: `app/build/reports/` (lint, detekt, tests HTML).

## Релиз шығару
```bash
# version.properties → 1.1.0, CHANGELOG, release-notes жаңартылды
git commit -am "chore(release): 1.1.0"
git tag -a v1.1.0 -m "1.1.0" && git push && git push origin v1.1.0
```
Actions → Release → `internal` job жасыл → `production` job «Waiting for review» → **Review deployments → Approve**.

## Альтернатива: Fastlane
GPP орнына Fastlane қалаған жағдайда: `fastlane supply --aab app-release.aab --track internal --json_key play.json`
және `fastlane supply --track internal --track_promote_to production --rollout 0.01`. Біз GPP таңдадық — Gradle ішінде, Ruby қажет емес.

Есепке скриншоттар: Actions тізімі (жасыл ✓ CI), PR беттегі checks, артефактілер, Release workflow графы
(internal → production «Waiting»), Approve диалогы, Play Console-да автоматты пайда болған релиз.
